Capabilities

Designed for Speed & Simplicity

Everything you need to manage and configure your favorite Minecraft setups seamlessly.

Modrinth Integration

Browse, search, install, and update your favorite mods, resource packs, and shaders directly inside the client without external browsers.

Multi-Loader Support

Easily manage and configure instances running Fabric, Quilt, Forge, and NeoForge across any supported Minecraft version.

Always Up-To-Date

Built-in self-updating technology ensures you always run the latest version without manually re-downloading installer files.

Isolated Environments

Every instance features its own isolated directory structure for mods, configs, saves, and assets to prevent mod conflicts.

Optimized Memory & CPU

Low desktop memory footprint engineered to maximize game FPS by dedicating system memory directly to Java processes.

Secure Microsoft Auth

Authenticate safely using official Microsoft OAuth 2.0 logins. Your account credentials stay local and encrypted.

Architecture

Engineered for Modrinth & Performance

Crispy Launcher is built as a fast proprietary client leveraging high-performance asynchronous networking, custom JVM argument optimization, and instant Modrinth REST API resolution.

Asynchronous Concurrent Downloads

Downloads modpack assets, Java runtimes, and libraries in parallel to minimize installation wait times.

Direct Modrinth REST V2 Integration

Queries project files, dependencies, and version hashes with zero intermediary proxy delay.

Frequently Asked Questions

Is Crispy Launcher free to download?

Yes! Crispy Launcher is a free proprietary Minecraft desktop launcher maintained by FryedCheese.

Is Crispy Launcher open source?

No, Crispy Launcher is free proprietary software developed and distributed directly through official releases.

How do Linux downloads work?

Download the .AppImage release, make it executable using chmod +x crispy-launcher-*.AppImage in your terminal, and run it.

Does Crispy Launcher support Fabric and Forge?

Yes, Fabric, Quilt, Forge, and NeoForge are fully supported with one-click loader installation and version switching.
