Frequently Asked Questions

Everything you need to know about Crispy Launcher.

Is Crispy Launcher completely free and open-source? ▼
Yes, Crispy Launcher is 100% free and open-source under permissible licensing. You can inspect all source code on our GitHub repository at any time.
How does Modrinth integration work? ▼
The launcher connects directly to the official Modrinth v2 API. You can search, filter, install, and auto-update mods, resource packs, and shaders directly inside your launcher instances.
Do I need to install Java manually? ▼
No! Crispy Launcher automatically detects the correct Java version needed for your selected Minecraft version and downloads isolated runtimes as needed.
How do I run the launcher on Linux? ▼
Download the Linux .AppImage file, grant execution permission in your terminal using chmod +x crispy-launcher-*.AppImage, and double click to run.
