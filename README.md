# Crispy Launcher

> A lightweight, modern desktop Minecraft launcher built with Electron and Node.js.

[![GitHub release](https://img.shields.io/github/v/release/Web-mc1/crispy-launcher?color=green&style=flat-square)](https://github.com/Web-mc1/crispy-launcher/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)

Crispy Launcher provides a fast, responsive, and seamless experience for launching Minecraft, managing game instances, and delivering smooth updates right to your desktop.

---

## Features

- **Fast & Lightweight:** Optimized Electron architecture for instant startup times.
- **Modern UI:** Clean, custom dashboard interface designed with simplicity in mind.
- **Auto-Updates:** Native support for seamlessly fetching the latest launcher releases directly from GitHub.
- **Instance & Build Management:** Easily manage your game profiles and dependencies.

---

## Download & Installation

You can get the latest pre-packaged installer directly from our official releases page:

[Download Latest Release](https://github.com/Web-mc1/crispy-launcher/releases/latest)

### System Requirements
* **OS:** Windows 10 / 11 (64-bit)
* **Java:** Java 17 or higher (recommended for newer Minecraft versions)
